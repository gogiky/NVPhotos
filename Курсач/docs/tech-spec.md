## 2. Назначение и цели создания системы

2.1. Назначение системы:

АС «NVPhotos» предназначена для представления услуг фотографа в сети Интернет,
демонстрации портфолио и достижений, а также для приёма заявок на съёмку через
каталог услуг и корзину с поддержкой промокодов. Связь с клиентом
осуществляется по указанному номеру телефона.

2.2. Цели создания системы:

- Обеспечение возможности онлайн-просмотра каталога услуг и портфолио.
- Автоматизация процесса оформления заказов на съёмку.
- Упрощение взаимодействия между клиентом и фотографом.
- Повышение конверсии посетителей сайта в клиентов.
- Снижение нагрузки на фотографа при приёме заявок.

---

## 3. Характеристика объектов автоматизации

3.1. Объектом автоматизации является деятельность частного фотографа по
предоставлению услуг фотографии.

3.2. Условия эксплуатации: работа в браузере на стороне клиента, работа
администратора в панели управления через браузер.

3.3. Характеристики окружающей среды: обычные условия офиса.

---

## 4. Требования к системе

### 4.1. Требования к структуре системы в целом

4.1.1. Система должна включать следующие подсистемы (модули):

- Модуль авторизации администратора.
- Модуль каталога услуг.
- Модуль портфолио с фильтрацией по категориям.
- Модуль корзины.
- Модуль промокодов.
- Модуль оформления заказов.
- Модуль управления заказами.
- Модуль отзывов и достижений.
- Модуль загрузки изображений.
- Модуль обратной связи (форма контактов).

4.1.2. Архитектура системы: трёхуровневая (клиент — сервер — база данных).

4.1.3. Режим функционирования: круглосуточный доступ через сеть Интернет.

### 4.2. Требования к функциям, выполняемым системой

**4.2.1. Функции для гостя (посетителя сайта):**

- Просмотр главной страницы.
- Просмотр каталога услуг.
- Поиск услуг по названию.
- Просмотр портфолио с фильтрацией по категориям.
- Просмотр достижений.
- Просмотр отзывов.
- Отправка нового отзыва (с последующей модерацией).
- Просмотр страницы контактов.
- Отправка сообщения через форму обратной связи.
- Добавление услуг в корзину.
- Удаление услуг из корзины.
- Применение промокода.
- Оформление заказа: ввод имени, номера телефона, желаемого времени съёмки,
  комментария.

**4.2.2. Функции для администратора (фотографа):**

- Авторизация в панели управления.
- Управление услугами:
  - добавление;
  - редактирование;
  - удаление;
  - включение/отключение активности;
  - управление популярностью (для слайдера).
- Управление портфолио:
  - добавление работ с загрузкой картинки с компьютера;
  - редактирование;
  - удаление;
  - привязка к категории;
  - управление порядком сортировки.
- Управление промокодами:
  - создание;
  - редактирование;
  - удаление;
  - активация/деактивация;
  - установка срока действия и лимита использования.
- Управление заказами:
  - просмотр всех заказов;
  - смена статуса (Новый, Подтверждён, Выполнен, Отменён).
- Управление отзывами:
  - публикация;
  - снятие с публикации;
  - удаление.
- Управление достижениями:
  - добавление;
  - редактирование;
  - удаление.
- Просмотр и обработка сообщений с формы обратной связи.

### 4.3. Требования к видам обеспечения

**4.3.1. Требования к информационному обеспечению:**

Состав данных:

- категории услуг и портфолио;
- услуги;
- работы портфолио;
- достижения;
- отзывы;
- промокоды;
- заказы;
- состав заказов;
- администраторы.

Структура данных: реляционная база данных Microsoft SQL Server, 9 таблиц.

**4.3.2. Требования к программному обеспечению:**

Клиентская часть:

- работает в современных браузерах: Chrome, Firefox, Edge, Safari;
- не требует установки дополнительных программ и плагинов;
- адаптивная вёрстка (десктоп, планшет, мобильный).

Серверная часть:

- Node.js (LTS);
- Express;
- драйвер mssql;
- multer для загрузки файлов.

**4.3.3. Требования к техническому обеспечению:**

- Рабочая станция администратора: Windows 10/11, 4 ГБ ОЗУ и более.
- Сервер: Node.js, MS SQL Server Express.
- Клиентские устройства: любые современные браузеры.

**4.3.4. Требования к организационному обеспечению:**

- Управление системой осуществляется администратором (фотографом).
- Персональные данные клиентов (имя, телефон) используются только для связи и
  обработки заказа.
- Модерация отзывов перед публикацией.

### 4.4. Общие технические требования

**4.4.1. Требования к надёжности и безопасности:**

- Авторизация администратора через специальное окно входа.
- Токен администратора хранится в защищённом виде.
- Изменение или удаление информации сопровождается окном подтверждения.
- Разграничение прав доступа по ролям.
- Валидация всех пользовательских данных на сервере.
- Защита от SQL-инъекций через параметризацию запросов.
- Ограничение загружаемых файлов по расширению и размеру (до 10 МБ).

**4.4.2. Требования к эргономике и технической эстетике:**

- Интерфейс должен быть интуитивно понятным.
- Адаптивная вёрстка для корректного отображения на различных устройствах.
- Единый стиль оформления на всех страницах.
- Единая цветовая схема (акцент — золотистый #C9A227).

**4.4.3. Требования к эксплуатации, техническому обслуживанию и ремонту:**

- Условия обычного офиса.
- Резервное копирование базы данных — не реже одного раза в неделю.
- Резервное копирование загруженных изображений.
