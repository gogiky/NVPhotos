# Руководство пользователя

**Сайт-визитка фотографа NVPhotos**
Версия: 1.0

---

## 1. Введение

Данное руководство описывает работу с публичной частью сайта-визитки фотографа
NVPhotos. Сайт предназначен для просмотра услуг, портфолио, отзывов и оформления
заказов на съёмку в онлайн-режиме.

Сайт работает в любом современном браузере (Chrome, Firefox, Edge, Safari) и не
требует установки дополнительных программ.

---

## 2. Основные разделы сайта

### 2.1 Главная страница

На главной странице расположены:

- Приветственный блок с именем фотографа.
- Краткий список услуг.
- Последние отзывы клиентов.

Кликните по карточке услуги, чтобы перейти на страницу с полным описанием.

### 2.2 Страница «Услуги»

Страница содержит:

- **Слайдер популярных услуг** — с автопрокруткой и стрелками по бокам.
- **Каталог всех услуг** — сетка карточек с фильтром поиска.
- **Кнопка «Оформить заказ»** на каждой услуге — добавляет её в корзину.

### 2.3 Страница «Портфолио»

Портфолио разбито по категориям:

- Портреты
- Пейзажи
- Предметы
- Свадьбы
- и другие

Сверху — кнопки фильтрации по категориям. Клик по кнопке показывает только
работы выбранной категории. Кнопка «Все работы» сбрасывает фильтр.

### 2.4 Страница «Достижения»

Список достижений фотографа: участие в конкурсах, публикации, награды,
сертификаты. Каждое достижение содержит год, заголовок и краткое описание.

### 2.5 Страница «Отзывы»

Раздел содержит:

- Список опубликованных отзывов клиентов.
- Форму добавления нового отзыва.

**Как оставить отзыв:**

1. Заполните поле «Ваше имя».
2. Выберите оценку от 1 до 5.
3. Напишите текст отзыва.
4. Нажмите «Отправить отзыв».

Отзыв будет опубликован после проверки администратором.

### 2.6 Страница «Контакты»

На странице размещены:

- Телефон, email, Telegram, VK.
- Форма обратной связи: имя, контакт, сообщение.

После отправки сообщение сохраняется и администратор увидит его в панели
управления.

## 3. Работа с корзиной

### 3.1 Добавление услуги в корзину

Нажмите кнопку **«В корзину»** на карточке услуги. Кнопка на короткое время
станет зелёной и покажет «Добавлено ✓». Счётчик в шапке увеличится.

### 3.2 Просмотр корзины

Кликните по пункту **«Корзина»** в шапке сайта — откроется всплывающее окно с:

- Списком добавленных услуг.
- Итоговой суммой.
- Полем для промокода.
- Кнопкой «Оформить заказ».

### 3.3 Удаление услуги из корзины

В корзине у каждой услуги есть крестик «×». Кликните по нему и подтвердите
удаление во всплывающем окне.

### 3.4 Применение промокода

Введите промокод в поле «Промокод» и нажмите «Применить». Если промокод
действителен, скидка отобразится в блоке «Итого». Если нет — появится сообщение
об ошибке.

---

## 4. Оформление заказа

1. Откройте корзину.
2. Проверьте состав и сумму.
3. Нажмите **«Оформить заказ»**.
4. Заполните форму:
   - **Имя** — как к вам обращаться.
   - **Телефон** — для связи.
   - **Желаемое время съёмки** — например, «15.05.2026, 14:00».
   - **Комментарий** (необязательно) — пожелания, место съёмки, детали.
5. Нажмите «Подтвердить заказ».

После успешной отправки появится сообщение с номером заказа. Фотограф свяжется
с вами по указанному номеру телефона.

---

## 5. Возможные проблемы

| Проблема | Решение |
|---|---|
| Кнопка «В корзину» не нажимается | Проверьте соединение с интернетом или обновите страницу (Ctrl+F5) |
| Промокод не применяется | Проверьте, что срок действия не истёк |
| Ошибка при оформлении заказа | Проверьте, что все обязательные поля заполнены, а формат даты указан верно |
| Картинки не отображаются | Обновите страницу или обратитесь к разработчику |
